# Svar fra kunden

Fyll inn under hvert spørsmål når svarene kommer. Kolonnen "Brukes til" viser hvor på siden svaret havner.
Merk alt vi antar med **(antatt)** til det er bekreftet.

## Om firmaet

| Spørsmål | Svar | Brukes til |
| --- | --- | --- |
| Firmanavn, org.nr., nettside i dag | | Topp, bunntekst, Brreg-sjekk |
| Hva kjører de mest av (pakker, paller, kjøl, flytting, bud) | | Hvilke grener siden får |
| Hvilke selskaper kjører de for, og kan vi nevne dem | | Tillit ("kjører for ..."), eller holdes generelt |
| Område | | Overskrift, kart i oversiktsscenen |
| Antall biler og typer | | Bilvalget i steg 2, 3D-referanse |

## Kunder

| Spørsmål | Svar | Brukes til |
| --- | --- | --- |
| Typiske kunder, og hvem de vil ha flere av | | Målgruppe, annonsesett |
| Hva de gjør bedre enn andre, hva fornøyde kunder sier | | Hovedløfte, støtteargumenter |
| Prising, og om pris kan vises | | Tilbudsseksjonen |

## Forslag til historie (fylles ut etter svarene)

Felles start: oversikt over området, ordren kommer inn, velg vare.
Grener: én per varetype han faktisk kjører mest av, maks tre.
Felles slutt: kveldsoversikt og tilbudsskjema.
